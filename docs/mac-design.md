# Hera for Mac — 디자인 · UI/UX · 단축키 · 파일 명세

> 이 문서만 보고 맥용 Hera 를 만든다. 윈도우판(Hera for Windows, 2026-11 개편 a16~a19)과 **기능·스펙·저장 키·통신 규격은 똑같이**, **화면은 맥 방식**으로.
> 함께 읽을 문서: `docs/spec.md`(기능·이벤트·명령 목록 — 윈도우 개편과 함께 갱신), `docs/hera-link-protocol.md`(파일 채널 규격), `docs/mac-port.md`(모듈별 맥 대응·빌드).
> 윈도우판 시안: `.omc/prototypes/win-tray-v3.html` — 동작(흔들기 받침·포탈)의 기준. 맥은 같은 동작을 맥 재질로.

---

## 0. 원칙

1. **쉽고 빠르게.** 한 화면, 크기가 튀지 않게, 확인 창·추가 창 없이. 문구는 짧고 자연스러운 한국어.
2. **맥답게.** 캡슐·노치 놀이 없이, 맥 사용자가 이미 아는 자리(메뉴 막대·제어 센터·알림 센터·Finder)에 둔다.
3. **가볍게.** 쉬는 동안(Idle) Hera 전체 메모리 ≤ 150MB(Activity Monitor, WebKit 프로세스 포함), 쉬는 동안 애니메이션·폴링 0. '동작 줄이기'(Reduce Motion)를 따른다.
4. **Deskflow 앱 없이.** 맥 사용자는 Hera 하나만 켠다. 입력 공유 엔진은 Hera 안에 숨겨 넣는다 (5장).

## 1. 기능 (윈도우와 같음 — 이것 말고는 없다)

| # | 기능 | 맥에서 하는 일 |
|---|---|---|
| 1 | **연결** | 윈도우(서버)와 같은 네트워크에서 자동으로 찾고, 처음 한 번 6자리 숫자로 짝 맞춤. 마우스·키보드는 내장 엔진(클라이언트)으로 받는다 |
| 2 | **클립보드 공유** | 엔진이 PC↔맥 클립보드를 맞춘다. 켜고 끄기만 (기록 목록 화면 없음) |
| 3 | **파일 보내기 + 선반** | 선반 = 잠깐 올려 두는 파일 자리. 맥→윈도우 보내기, 윈도우에서 받은 파일도 선반에 |
| 4 | **메모** | 빠른 메모(Enter 저장) + 메모 보드 창 + "텍스트 편집기로 열기" |
| 5 | **넘어갈 때 물결** | 커서가 맥으로 들어온 자리(진하게)·떠난 자리(옅게)에 파란 물결 |
| 6 | **흔들어 커서 찾기** | 마우스를 좌우로 흔들면 커서 둘레에 물결 |
| 7 | **꾸미기** (스위치 1개, 기본 끔) | 날씨·계절 효과 · 자리 비움 화면(아스키/효과) · 메뉴 막대 펫 |
| 8 | **설정** | 위 기능의 설정만 |

**없는 것 (윈도우에서도 뺐다):** 캡슐/허브, 할 일, 달력·일정 알림, 채팅·Team, 터미널·아라·MCP, OCR, 상용구, LP 런처, 최근 복사 목록, 펫 가져오기·편집.

## 2. 화면 구성 (맥 방식)

| 윈도우판 | 맥판 | 맥 구현 |
|---|---|---|
| 작업 표시줄 트레이 아이콘 | **메뉴 막대 아이콘** (`NSStatusItem`) | 템플릿 이미지(흑백, 다크/라이트 자동). 맥 연결됨 = 아이콘 오른쪽 아래 작은 초록 점 |
| 트레이 클릭 → 빠른 설정 자리 패널 | **메뉴 막대 아이콘 클릭 → 제어 센터 같은 패널** | `NSPanel`(nonactivating, `.statusBar` 레벨) 또는 `NSPopover`(화살표 없음 `.transient`). 아이콘 바로 아래, 폭 340pt |
| 오른쪽 아래 알림 카드(토스트) | **macOS 알림** (`UNUserNotificationCenter`) | 알림 센터에 쌓임. 짝 맞추기 숫자는 패널 안에 (알림을 누르면 패널 열림) |
| 작업 표시줄 위 펫 | **메뉴 막대 펫** (꾸미기 켰을 때) | Hera 아이콘 자리에 펫 스프라이트가 대신 앉는다(18pt 높이). 클릭 = 패널. 잠들기·파일 반응 |
| 파일 끌다 흔들면 받침 | **같음** — 커서 위에 받침 | `NSPanel` nonactivating, `ignoresMouseEvents=false` 일 때만 드롭 대상 |
| 맥 쪽 가장자리 포탈 | **윈도우 쪽 가장자리 포탈** | 투명 클릭 통과 창 + Core Animation(또는 웹뷰 캔버스) |
| 설정 창 (Fluent) | **맥 설정 창** (시스템 설정 모양) | 왼쪽 사이드바 + 오른쪽 그룹 폼. `⌘,` 로 열기 |
| 메모 보드 창 | 같은 기능의 맥 창 | 일반 창(제목 막대·신호등), 크기·위치 기억 |

### 2.1 패널 (메뉴 막대 아이콘 클릭)

위에서 아래로 (윈도우 시안과 같은 순서·같은 문구):

```
┌──────────────────────────────────────┐
│ [💻] DEV-KIMJUNYOUNG 연결됨     (◉ 스위치) │  ← 연결 줄: 상대 이름 · 상태 · 켜기/끄기
│      왼쪽 · 마우스를 왼쪽 끝으로 밀면 넘어가요 │
│ ┌────────┐ ┌────────┐ ┌────────┐      │
│ │ 📋     │ │ ◎      │ │ ↖      │      │  ← 타일 3개 (켜짐 = 강조색 채움)
│ │클립보드│ │넘어갈 때│ │흔들어  │      │
│ │ 공유   │ │ 물결   │ │커서 찾기│      │
│ └────────┘ └────────┘ └────────┘      │
├──────────────────────────────────────┤
│ 선반                            3개  │
│ ┆ 파일을 여기에 놓으면 올려 둬요 ┆     │  ← 드롭 영역
│ [XLSX] 서버정보.xlsx  이 PC·어제  → ↗ ✕│  ← 줄: PC로 보내기 · 열기 · 빼기 (마우스 올리면)
│ [PNG ] 스크린샷.png   PC에서 받음      │
├──────────────────────────────────────┤
│ 메모                        모두 보기 │
│ [메모 쓰고 Enter · 줄바꿈은 Shift+Enter] │
│ ▍회의실 B 3시 → 4시로 변경      10:21 │  ← 최근 3개
├──────────────────────────────────────┤
│ 꾸미기  날씨·계절 효과·자리 비움·펫 (◯) ⚙ │
└──────────────────────────────────────┘
```

- **짝 맞추기 중**이면 연결 줄 아래에 큰 숫자 `482 913` + [같아요] [아니요] (120초).
- **연결 꺼짐/찾는 중**: 연결 줄 = "Windows Hera를 찾는 중 · 같은 Wi‑Fi인지 확인하세요" + 타일 흐리게.
- 바깥 클릭·`Esc`·아이콘 다시 클릭 = 닫힘. 열 때 메모 입력에 포커스 주지 않는다(바로 타이핑 원하면 `⌘N`).
- 열기 애니메이션: 아래로 6pt + 불투명 0→1, 200ms 스프링(반동 없음). 동작 줄이기 = 페이드만.

### 2.2 흔들기 받침 (파일을 끄는 중에 흔들면)

- **조건**: 파일을 끌고 있음(드래그 페이스트보드에 파일 URL) + 좌우로 0.7초 안에 방향 3번 넘게 바뀜(한 번에 25pt 넘게). 끌지 않고 흔들면 = 커서 찾기 물결.
- **모양**: 커서 위 22pt 에 유리 카드(반경 16pt, `NSVisualEffectView` `.hudWindow` 또는 `.popover`), 아래로 꼬리. 제목 "놓을 곳을 고르세요". 칸 2개(148×112pt, 반경 12pt):
  - **선반에 올리기** — 노란 원(#FFD66B→#F59F00) 아이콘, 오른쪽 위에 선반 개수
  - **PC로 보내기** — 파란 미니 포탈 원(가운데 남색 → 바깥 하늘색) + 둘레에 도는 빛 고리. 윈도우 Hera 와 파일 채널이 안 붙어 있으면 흐리게 + "Windows Hera 연결 필요"
- **움직임**: 커서 쪽에서 0.55→1 스프링(살짝 튐, 420ms). 칸 위로 오면 4pt 떠오르고 1.06배 + 색 테두리 빛. 놓으면 아이콘이 꿀꺽(1.14→0.82→1). 드래그 끝나면 사라짐.

### 2.3 포탈 (윈도우 쪽 가장자리로 파일을 들고 가면)

- **어디**: 연결 배치에서 윈도우와 맞닿은 맥 화면 가장자리 구간 (윈도우가 보내는 링크 구간 = `docs/spec.md`의 배치 메시지). 그 구간 밖 가장자리에서는 안 열린다.
- **열림**: 가장자리에서 220pt 안으로 들어오면 커지기 시작, 50pt 안이면 다 열림. 다 열리면 "놓으면 Windows로" 말풍선.
- **모양** (윈도우 시안과 같음): 가장자리에 반쯤 걸린 세로 타원(104×168pt). 안쪽 깊은 남색(#02060F→#071A3C→#1554B8→#4FB4FF), 소용돌이 팔 4개, 안으로 빨려 드는 빛 입자 ~90개(가산 혼합), 빛나는 테두리 + 흐르는 흰 하이라이트 3개, 가장자리 세로 빛줄기, 주변 파란 번짐.
- **보내기**: 놓으면 파일 아이콘이 포탈 둘레를 2바퀴 돌며 작아지고 밝아져 빨려 듦(900ms) → 섬광 → 반원 충격파 → 포탈 닫힘. 동시에 파일 채널로 전송 시작.
- **윈도우 쪽**: 받으면 윈도우 가장자리(들어온 자리)에 포탈이 잠깐 열리고 파일이 튀어나와 선반으로 (윈도우판이 처리).
- **성능**: 끄는 동안·애니메이션 중에만 그린다. 닫히면 창 숨김 + 렌더 0. 동작 줄이기 = 소용돌이 멈춤, 빛만.

### 2.4 물결 (넘어갈 때 · 흔들어 찾기)

- 파란 동심원 3개(#3C9AFF 바깥 → 하늘색 안), 600ms 동안 커지며 사라짐. 네이티브 창 1개를 처음 한 번 만들고 재사용(`docs/mac-port.md` 5-B).
- 넘어갈 때: `crossed{enter:true,x,y}` → 그 자리 진하게. 떠날 때 → 내 커서 자리 옅게.
- 흔들어 찾기: 30Hz 커서 표본(`NSEvent.mouseLocation`), 윈도우 `watch::Shake` 와 같은 판정.

### 2.5 메뉴 막대 펫 (꾸미기 켰을 때)

- Hera 메뉴 막대 아이콘 대신 펫이 앉는다(높이 18pt, 폭 ≤ 28pt). 기본 펫 스타일만(설정 > 꾸미기에서 고르기, `pet.kind`).
- 상태: 평소 가끔 깜빡임/꼬리 · 2분 조용하면 잠듦(애니메이션 0) · 파일 받음/보냄 = 짧게 뛰어오름 · 연결 끊김 = 시무룩. 클릭 = 패널.
- 전체화면 앱(메뉴 막대 숨김)에선 자연히 안 보임.

## 3. 키보드 · 마우스

### 3.1 Hera 단축키 (전역 단축키는 없다 — 메뉴 막대 클릭)
| 키 | 어디서 | 동작 |
|---|---|---|
| 클릭 | 메뉴 막대 아이콘/펫 | 패널 열기·닫기 |
| `Esc` | 패널·받침·메모 보드 | 닫기 / 끌기 취소 |
| `Enter` | 메모 입력 | 저장 |
| `Shift+Enter` | 메모 입력 | 줄바꿈 |
| `⌘N` | 패널 | 메모 입력으로 이동 |
| `⌘,` | 패널 | 설정 |
| `⌘⌫` | 선반 줄(선택) | 선반에서 빼기 (파일은 지우지 않음) |
| `Space` | 선반 줄(선택) | 훑어보기(Quick Look) |
| `⌘Q` | 어디서든 | 종료 (메뉴 막대 오른쪽 클릭 메뉴에도) |

### 3.2 윈도우 키보드로 맥을 쓸 때 (커서가 맥에 있을 때)
- **수식키 바꾸기는 엔진이 한다** (윈도우가 엔진 설정에 넣음). 기본 '윈도우 습관': 윈도우 `Ctrl` → 맥 `⌘`, 윈도우 `Win` → 맥 `Ctrl`. 그래서 윈도우 `Ctrl+C/V/Z` 가 맥에서 그대로 복사·붙여넣기·되돌리기.
- **한/영**: 윈도우 한/영(오른쪽 Alt) →
  - 맥 Hera 와 파일 채널이 붙어 있으면 `ime{toggle}` 을 받는다 → 맥 Hera 가 `TISSelectInputSource` 로 한국어↔ABC 전환 → `ime{state, source:"ko"|"en"}` 회신.
  - 붙어 있지 않으면 윈도우가 엔진으로 맥 `^Space` 를 보낸다 (a15). 맥 기본 '이전 입력 소스' 단축키가 `^Space` 여야 함.
- '단축키만'(shortcuts) 프리셋이면 맥 Hera 가 `CGEventTap` 으로 엔진이 넣은 `Ctrl+C/V/X/Z/A/S/F/T/W/R/L/Q(+Shift)` 만 `⌘` 로 바꾼다.

## 4. 파일 · 저장

| 무엇 | 위치 |
|---|---|
| 설정·상태 store | `~/Library/Application Support/dev.hera.dock/hera.json` (윈도우와 **같은 키**) |

| 메모 텍스트 내보내기("텍스트 편집기로 열기") | `~/Library/Application Support/dev.hera.dock/notes/<id>.txt` → `open -e` |

### 4.1 store 키 (윈도우와 똑같이)
| 키 | 값 | 뜻 |
|---|---|---|
| `link.enabled` | bool | 연결 켜기 |
| `link.cfg` | `{me, peer, side, port, tls, doubleTap, filePort, keymap, keyRows, ime}` | 연결 설정 |
| `link.share` | `{clip: bool}` (기본 켬) | 클립보드 공유 |
| `link.key` / `link.peerPk` / `link.peerName` | hex / hex / string | 파일 채널 장기 키 · 짝 맞춘 상대 |
| `link.macMonitors` | `[{id, rect}]` | (윈도우 쪽) 맥 모니터 |
| `link.layout` | `{at:{id:[x,y]}}` | (윈도우 쪽) 배치 캔버스 |
| `ripple.enabled` | bool (기본 true) | 넘어갈 때 물결 |
| `locator.enabled` | bool (기본 true) | 흔들어 커서 찾기 |
| `deco.enabled` | bool (기본 **false**) | 꾸미기 |
| `pet.kind` | string (`cat`, `penguin` …) | 펫 스타일 |
| `note:<id>` | `{id, text, color(0..5), x, y, w, h, at?}` | 메모 (보드 자리 포함) |
| `note.color` · `board.rect` | 고른 색 · 메모 보드 창 `[x,y,w,h]` | |
| `shelf:<id>` | `{id, path, at(ms), from:"pc"\|"mac", sent?}` (최대 8) | 선반 — 이름은 path 에서 |
| `fx.city` · `fx.coords` · `fx.weather` · `ascii.idleMin` | | 꾸미기 효과 · 자리 비움 대기 분(기본 10) |

> 정확한 필드·이벤트 이름은 윈도우 개편 결과인 `docs/spec.md` 가 최종 기준. 이 표와 다르면 spec.md 를 따른다.

## 5. 연결 — Deskflow 없이

1. **입력 엔진 = 숨긴 deskflow-core 클라이언트** (윈도우가 서버 엔진을 숨겨 넣은 것과 같은 방식, GPL-2.0 + OpenSSL 예외, 라이선스 동봉, 개인 사용). 사용자는 Deskflow 앱을 설치·실행하지 않는다.
   - 바이너리: Deskflow 1.27 맥 빌드의 `deskflow-core` + Qt·OpenSSL 프레임워크를 `src-tauri/resources/link/` 로 (`scripts/fetch-deskflow.sh`). 항상 `--new-instance`.
   - INI: `computerName` = 윈도우 설정의 맥 이름(`link.cfg.peer`, 기본 "MacBook"), `remoteHost` = 비콘 보낸 주소, `port=24800`, TLS 켬.
   - 사용자 Deskflow.app 이 실행 중이면 엔진을 띄우지 않고 패널에 "Deskflow를 먼저 종료하세요".
2. **찾기·짝 맞추기·파일**: `link_files.rs` 그대로 (`discover()` → `connect()`, 끊기면 1→2→4…30초 재시도). 비콘 UDP 24811, 파일 TCP 24810.
3. **권한** (처음 실행 때 한 화면에서 안내 — 체크 3개, 각 [열기] 버튼이 해당 시스템 설정 화면으로):
   - **로컬 네트워크** — 없으면 비콘 수신·접속이 오류 없이 막힌다 (가장 흔한 "아무 반응 없음" 원인)
   - **손쉬운 사용** — 엔진의 입력 주입
   - **입력 모니터링** — 엔진의 입력 감시
4. 장기(나중): 엔진까지 Hera 자체 구현 — 이미 있는 암호 채널로 입력 이벤트 전달. 지금은 1번으로 충분.

## 7. 맥 수락 시험

1. `cargo test --lib`(link_files 루프백 포함) · `npx tsc --noEmit -p .` 통과, `npx tauri build` 로 .app.
2. 메뉴 막대 아이콘 클릭 → 패널, 다른 앱 포커스를 뺏지 않는다. `Esc`·바깥 클릭으로 닫힘.
3. 윈도우 Hera 연결 켬 → 맥이 비콘을 받아 접속 → 양쪽 6자리 → '같아요' → 마우스가 넘어오고 넘어갈 때 양쪽 물결.
4. 윈도우 키보드 한/영 → 맥 입력 소스 전환. `Ctrl+C/V` 가 맥에서 복사·붙여넣기.
5. 클립보드 공유 타일 끄면 복사가 건너가지 않는다.
6. 파일을 끌다 흔들면 받침 → 선반/PC로. 윈도우 쪽 가장자리로 끌면 포탈 → 놓으면 빨려 들어가고 윈도우 선반 + `Downloads\Hera` 에 착지. 반대 방향도.
7. 메모 Enter 저장 · Shift+Enter 줄바꿈 · 모두 보기 · 텍스트 편집기로 열기.
8. 꾸미기 켜면 메뉴 막대 펫·효과·자리 비움 화면, 끄면 전부 없음.
9. Deskflow.app 없이 동작. 권한 3개 안내 화면이 한 화면.
10. Idle 메모리 ≤ 150MB, 쉬는 동안 CPU ~0.
