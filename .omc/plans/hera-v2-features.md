# Hera v2 추가 기능 (2026-11-14 사용자 확정)

순서: **시안(브라우저 mockup, `npm run dev` → `?surface=all`) → 사용자 "OK" → 개발**. 성능(idle ≤150MB, idle CPU <1%)은 여전히 최우선.

## 넣는 것
1. **클립보드 기록** — 최근 텍스트 20개, **메모리에만**(파일 저장 없음, 재시작 시 사라짐). ⌘K 팔레트에서 검색어 없을 때 "최근 복사" 섹션 + 검색 시 함께 매칭. 선택 = 클립보드에 다시 넣기(+팔레트 닫기). 실제 앱: Rust `AddClipboardFormatListener`(폴링 없음).
2. **앱 묶음(독 폴더)** — 독 슬롯 하나 = 여러 앱. 아이콘은 2×2 미니 격자. 클릭 → 독 위로 격자 팝오버(맥 스택 느낌, 스프링). 패널 라이브러리에서 묶음 만들기/앱 넣고 빼기. store: `group:<id>` {title, recordIds[]}.
3. **Island으로 파일 끌어 놓기** — 파일을 끌고 Island 위로 오면 Island이 "선반에 놓기" 드롭존으로 펼쳐짐 → 놓으면 독 선반에 추가(기존 선반 로직 재사용, 최대 4개).
4. **아스키 아트** — 작은 장면(독 위젯 1칸)이 1~2초마다 몇 글자만 바뀜. 장면은 계절·시간대에 맞춰 자동: 12월 트리(장식 반짝임), 밤 빌딩(창문 불 켜짐), 가을 나무(잎 떨어짐), 기본 산/바다 등. 직접 작성(라이브러리 추가 X).
   - 큰 화면: 위젯 **클릭 → 전체화면** 아스키(같은 장면 큰 버전), Esc/클릭으로 닫기.
   - **자리 비움 N분(기본 10분) → 자동 전체화면**(화면보호기처럼), 마우스/키 입력 시 닫힘. 전체화면 앱 사용 중엔 안 뜸.
5. **날씨·계절·시간대 전체화면 효과** — 투명 클릭통과 전체화면 창(필요할 때만 생성, 끝나면 파괴 → 평소 메모리 0).
   - **짧은 이벤트**(20~30초): 날씨 변화(비 시작, 눈 시작), 시간대 변화(해질녘 노을, 밤 달 뜸), 계절 첫날(단풍). 효과: 눈, 비, 단풍, 노을빛, 달(실제 위상)·별.
   - **스위치**: 트레이 + 패널 설정에서 켜고 끄기(효과 이벤트 on/off). 수동으로 "지금 보기"도.
   - **날씨**: Open-Meteo(키 없음), **도시 직접 입력**(패널 설정, 기본 서울, 지오코딩도 Open-Meteo), 30분마다 1회. 실패 시 계절·시간대만으로 동작.
   - 시안에서는 효과/시간/날씨를 바꿔보는 데모 컨트롤 필요.

## 뺀 것 (사용자가 불필요로 판단)
집중 타이머, 회의 카운트다운·참가 버튼, 시스템 상태 팝업.

## 2026-11-15 사용자 결정
- v2 시안 **승인** ("좋은것 같아 이대로가자") → 개발 진행. 개발 끝나면 **이 PC에 설치까지**.
- 크리스마스 트리 보강: 빙글빙글 회전 + **선물 상자가 떨어져 트리 아래 쌓임** + 다양한 효과(별 반짝임, 유성, 눈, 장식 반짝임 등).
- **독이 Windows 작업 표시줄을 대체**(사용자는 작업 표시줄을 자동 숨김으로 둘 예정). 독 표시는 지금처럼 **점 → 펼침** 유지. 시안 없이 **바로 개발**.
  - 실행 중인 모든 앱: 고정 안 된 앱도 독 오른쪽(구분선 뒤)에 자동 표시. 클릭 = 활성화, 활성 창이면 최소화 토글. 같은 앱 창 여러 개 → 창 목록 팝오버(제목 + 가능하면 DWM 썸네일 미리보기).
  - 알림 깜빡임: 앱이 FlashWindow 하면(작업 표시줄 주황 깜빡임) 독 아이콘/접힌 점에 표시. 셸 훅(RegisterShellHookWindow, HSHELL_FLASH).
  - 시작·트레이·빠른설정·알림센터 버튼: Win / Win+B(숨은 트레이) / Win+A / Win+N.
  - 하단 가장자리 충돌: 자동 숨김 작업 표시줄도 하단에서 튀어나옴 → 설정 "Windows 작업 표시줄 숨기기"(옵트인, Hera 실행 중에만 숨기고 종료 시 복원, 시작 시에도 상태 정리).
- 단계: (1) v2 네이티브 + 트리 보강 → (2) 작업 표시줄 기능 → (3) NSIS 설치 파일 빌드 → 이 PC 설치·실행 확인.
