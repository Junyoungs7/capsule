# Hera Team — 동료 PC와 달력·메모 공유 (2026-11-15 사용자 확정)

- 범위: **달력(일정)과 메모(포스트잇)만** 공유. 마우스·키보드·파일·클립보드는 공유하지 않음(그건 내 PC끼리 Hera Link).
- 단위: **공유 그룹**("개발팀", "배너 프로젝트" 등). 그룹마다 공유 달력 + 공유 메모판. 개인 일정·메모는 기본 비공개, 만들 때 "내 것 / 그룹" 선택.
- 권한: **그룹원 모두 편집**. 누가 바꿨는지 표시, 삭제는 되돌리기 가능(휴지통/기록).
- 보이기: 달력에 **그룹 색**으로 표시, **팀 일정 알림**(그룹별 on/off), **변경 소식**(누가 추가·수정하면 Island에 짧게). 바쁨/한가함은 하지 않음.
- 방식: 서버 없이 같은 사내망 P2P. 초대 = 6자리 코드(또는 초대 링크 문자열), 이후 암호화. 온라인인 그룹원끼리 동기화하고 늦게 켠 PC는 켜질 때 따라잡음(누구든 온라인 그룹원이 전달). 항목별 최종 수정 우선 + 삭제 표시.
- 사내망에서 자동 발견이 막히면 IP 직접 입력.
- 순서: 시안(그룹 만들기·초대·그룹 색 달력·공유 메모판·변경 소식) → 확정 → Hera Link 통신 위에 개발.
