# Hera A5 게이트 시트 (기록용 — 사용자 사전 승인, 2026-11-13)

설계는 사용자가 미리 승인했다. 이 시트는 월요일 검토용 기록이다. 세션이 잠긴 상태에서 측정했으므로 육안 확인은 맨 아래 스크립트로 미뤘다.

- 시안: `npm run dev` → `http://localhost:5173/?surface=all` (브라우저 시안, mock + localStorage)
- 실앱: `npm run tauri build -- --no-bundle` → `src-tauri\target\release\hera.exe` (트레이 → 종료)

## 2. 애니메이션 프레임 (릴리스 앱 웹뷰, rAF 간격, 60Hz)

측정 방법: `.omc/verify/b5-perf.mjs frames`. CDP로 릴리스 웹뷰에 §7 rAF 간격 스니펫과 longtask 옵저버를 넣고, 마우스는 `Input.dispatchMouseEvent`로 보냈다. 기준은 프레임의 95% 이상이 17.5ms 이하(1 vsync + 지터)이고 50ms를 넘는 long task가 0건인 것이다.

| 애니메이션 | 프레임 | ≤17.5ms | 최대 | long task |
|---|---|---|---|---|
| 점→독 펼침 + 확대 스윕 (1.5s) | 92 | 100% | 16.8ms | 0 |
| 독 접힘 (1.2s) | 73 | 100% | 16.8ms | 0 |
| Island idle→alert ×3 (각 3s) | 182/181/181 | 100% | 16.9ms | 0 |
| Island alert→idle ×3 (각 1s) | 61/61/61 | 100% | 16.8ms | 0 |
| 패널 열기/닫기 | 미측정 | — | — | — |
| 턴테이블 서랍 열기 (0.8s) | 50 | 100% (≤17ms) | 16.8ms | 0 |
| LP 드래그→스냅→바늘→가속 (3s) | 182 | 100% (≤17ms) | 16.8ms | 0 |

- ⚠ 잠금 세션에서 측정했다. rAF는 돌았지만 DWM 실제 표시(present)와 Layout/Style 매 프레임 여부는 DevTools Performance로 확인하지 못했다. 패널은 생성 직후에 열림 애니메이션이 돌아서 CDP를 붙이기 전에 끝난다(→ 수동 스크립트 7번).
- Stage A 시안 단계의 Chrome DevTools 수치는 계획에 기록되어 있지 않다(측정 기록 없음).

## 3. 실제 글라스 상태

- **독: 배경화면 페이크(B0-1 ②).** 배경화면을 1/4 해상도 캔버스에 블러로 구워 1회 그린다. 뒤의 앱 창이 아니라 **배경화면만** 보인다. 단색이나 실패 시에는 틴트로 돌아간다.
- Island: 블러 없는 짙은 판. 패널: OS Acrylic(포커스 창) + Win11 라운드 코너.
- 합성 스크린샷: `.omc/mockup-shots/30-real-composite-dock-open.png`, `30-real-composite-dot.png`. 실제 배경화면 위에 실앱 웹뷰 렌더(CDP)를 실제 창 위치에 얹은 것이다. 잠금 때문에 화면 실캡처는 아니다.

## 4. 시안과의 알려진 차이

- 독 글라스는 배경화면만 비친다(창 뒤 앱 아님). `apply_blur`는 창 rect 전체가 번져서 기각했다.
- 패널 Acrylic은 열기 애니메이션 중에도 창 전체에 즉시 보인다.
- LP 드래그는 턴테이블 창 안에서만 된다(창 간 드래그 없음). Island 크기는 고정 프리셋 4개다.
- 알림: 일정은 시작 시각에 1회 울린다(사전 알림 없음). '완료'는 할 일만 done 처리하고, 일정은 닫기만 한다. '다시 알림'은 `snooze` 필드(+10분)를 쓰며 원래 기한은 그대로 둔다.
- 놓친 알림(앱 종료·절전 중)은 기간 제한 없이 시각 순으로 1회 큐에 쌓인다.
- 전체화면 중에는 독/Island를 숨기고 알림을 보류했다가, 끝나면 순서대로 표시한다.

## 4-1. Stage C 상태 (2026-11-13)

- 완료: C1 턴테이블 창, C2 LP 세트, C3 팔레트, C4 배터리·파일 선반. 상세 수치는 계획 §6 'C 결과'.
- 메모리(릴리스 idle 3분): 턴테이블 보임·팔레트 숨김 상주 **99.5MB**(≤150MB 통과), 턴테이블 숨김 **85.6MB**. 팔레트 단축키→표시 p95 5.7ms(숨김 상주; 매번 생성 시 p95 309ms라 기각).
- 앱 종료 → 턴테이블 정지 1179/689ms(≤2.5s), idle CPU(턴테이블 보임·정지) 트리 0.23% / hera.exe 0.18%(1코어 기준, <1% 통과).
- 기본값 결정: 턴테이블은 기본 숨김(트레이/독 우클릭으로 켬, 숨기면 창 파괴), 팔레트는 시작 시 숨김 생성, 앱 PID 추적 없음(실행 집합 키로 판정), URL 레코드는 15초 뒤 정지, 선반 4칸.
- 시안과의 차이: 턴테이블 카드는 데크 바닥에서 끝나고 서랍은 카드 밖으로 내려온다(글리치 수정, 시안에도 반영). 팔레트 창에는 화면 어둡게 하기(scrim) 없음. 선반은 겹친 종이 더미 대신 파일 칩 4칸.
