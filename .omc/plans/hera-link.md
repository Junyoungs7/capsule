# Hera Link — Win↔Mac 마우스·키보드·클립보드·파일 (2026-11-15 사용자 확정)

목표: **Deskflow 앱 없이 Hera 하나로** 윈도우(메인, 서버)와 맥(클라이언트)을 함께 쓴다. 연결·설정·상태는 전부 Hera(Island·패널)에서.

## 결정
- 마우스·키보드 공유: **Deskflow 오픈소스 입력 엔진(deskflow-core)을 Hera 안에 내장**해 보이지 않게 실행(사이드카). 한/영·Cmd/Ctrl·화면 경계 등 검증된 동작을 그대로 씀. 별도 Deskflow 앱 설치·실행 없음. (GPL-2.0 — 개인 사용, 배포 안 함)
- 클립보드: 엔진의 클립보드 공유 사용 + Hera "최근 복사" 기록에도 반영(메모리만, 비밀번호 관리자 제외 규칙 유지).
- 파일: **Hera 자체 채널**(LAN, 페어링 후 암호화). Island/독 선반에 끌어 놓기 → Island이 삼키듯 접힘 → 상대 Island에서 튀어나와 상대 선반에 착지. 진행률은 Island에.
- 화면 전환 표시: 마우스가 맥으로 넘어가면 Island에 "→ Mac" 애니메이션, 돌아오면 "← Windows".
- 페어링: 윈도우 = 서버, 맥 = 클라이언트. 같은 네트워크에서 자동 발견, 처음 1회 6자리 코드 확인(엔진 TLS 지문 + Hera 채널 키).
- 화면 배치: 패널 설정에서 맥 화면을 윈도우 화면의 좌/우/위/아래로 끌어 놓기. 기존 Deskflow 설정 가져오기 버튼.
- 맥용 Hera: **사용자가 맥에서 Claude Code 실행** → 거기서 맥 빌드·시험. 윈도우 쪽(서버 + 통신 규칙)은 이 PC에서 먼저.

## 주의
- 사용자가 지금 Deskflow 1.27(C:\Program Files\Deskflow)로 실제 맥을 쓰는 중 — **개발·시험 중 사용자의 Deskflow를 끄거나 포트(24800)를 뺏지 말 것.** Hera 내장 엔진 스위치 기본 OFF, 전환은 사용자가 직접.
- 회사 보안 프로그램이 입력 엔진/파일 전송을 막을 수 있음 → 문제 시 Island/패널에 원인 표시.

## 추가 확정 (2026-11-15)
- 모니터별 배치: 양쪽 듀얼 모니터를 각각 끌어 배치 → 엔진 설정은 가장자리 범위(%) 링크로 변환.
- 넘어갈 때 파란 물결: 들어간 화면의 교차 지점에서 동심원 물결(~0.6s), 떠난 쪽엔 옅게. 네이티브 레이어드 창(웹뷰 X).
- 상대 PC 화면 제어: 아스키/화면보호기/효과를 상대 PC에 켜고 끄기(패널·⌘K·Island). 옵션: 한쪽만 N분 쓰면 상대에 자동 화면보호기(기본 off).
- 화면 경계 너머 파일 끌기, 할 일·달력 동기화(알림은 커서가 있는 PC에만), 커서 찾기(흔들면 파란 물결).
